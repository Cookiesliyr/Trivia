# Trivia
Trivia is a generic Trivia program i made in 2023, i don't remember much of it, but let's make a simple tutorial

<img width="734" height="543" alt="image" src="https://github.com/user-attachments/assets/263f9553-24ad-47c1-bacc-5ef3beec45eb" /> <br><br>

On the left side of the main program you can see the list of quizes you have, you can create new ones by clicking on the '+' button or selcing Quiz => Create Quiz

<img width="736" height="548" alt="image" src="https://github.com/user-attachments/assets/90bd1666-7630-45cd-8120-e19e4f69c0eb" /> <br><br>

The first tab is for questions Category, this is optional, it is up to the user how to catagorize the questions, you can add them from here

<img width="863" height="564" alt="image" src="https://github.com/user-attachments/assets/07e7809f-c0c4-40a8-be6e-ff83d77dbdf2" /> <br><br>

The Second tab is to make quizes, the first list on the left hold the quizes, each quiz can have as many questions as you like

<img width="863" height="564" alt="image" src="https://github.com/user-attachments/assets/84a80a22-3e6b-4f89-bde3-806f336074f6" /> <br><br>

The middle list is the questions in the selected quiz

<img width="863" height="564" alt="image" src="https://github.com/user-attachments/assets/90641fdd-313b-4444-a4a5-983824483260" /> <br><br>

All questions have a question section and diffculty. 
Each question can be either one of the three types: 'Choices', 'Type the answer' or 'True or false'. 

Let's take a look on Chocies choice!

<img width="863" height="564" alt="image" src="https://github.com/user-attachments/assets/98515262-0c61-4196-956c-7d3f7bc358db" /> <br><br>

For Choices you need to pick what is the correct answer, it starts from 0. And you can add as many choices as you like. You could check "Random Choices" if you want the choices shuffled for this question when it picked in the trivia, this might not look nice when the choices are dates.

For the 'Type' we will have this

<img width="863" height="564" alt="image" src="https://github.com/user-attachments/assets/a87b85ed-fe9f-45bc-b4a7-40ef87c11f9f" /> <br><br>

Here you can enter all accepted forms of the answers, you could check "Accept Partial" if you can let the users have partial answers, that's useful for charactors names for example

For 'True or false' it can't be more simple

<img width="863" height="564" alt="image" src="https://github.com/user-attachments/assets/c64d7f30-696e-40f1-a8b2-f65ac529dd56" /> <br><br>

After you made enough questions you can click 'Save & exit', or 'Save Changes' if you want to add mroe quizes and questions. back to the program

You can see more options if you click on the '>' arrow

<img width="734" height="543" alt="image" src="https://github.com/user-attachments/assets/6a34d457-908a-4719-aab7-e2d16f69c1a2" /> <br><br>

You could start the trivia right away by clicking 'Play'

<img width="734" height="543" alt="image" src="https://github.com/user-attachments/assets/3492882a-7439-4aa9-9ba4-cd411334eb41" />
